# Semiconductor Paper Study Agent

반도체 및 전자공학 관련 논문·연구 노트·기술 자료를 읽고, 필요한 배경 개념을 추가로 검색하여 학습 및 발표 준비 자료로 정리하는 LangChain 기반 AI Agent입니다.

이번 과제에서는 Agent Loop뿐 아니라 Agent 실행을 제한하고 관찰하는 Harness와, 결과를 검증한 뒤 필요하면 Feedback을 주어 다시 실행하는 Loop Engineering을 함께 구현했습니다.

---

## 1. Agent 목적

전자공학 및 반도체 관련 자료를 공부할 때 다음 작업을 지원하는 Agent입니다.

- 로컬에 저장된 논문 노트 및 기술 자료 읽기
- 자료 이해에 필요한 배경 개념 검색
- 핵심 내용 및 전공 개념 정리
- 발표에서 강조할 내용 정리
- 예상 질문 생성
- 완성된 학습 자료를 Markdown 파일로 저장

최종 학습 결과는 다음 네 개의 섹션으로 구성됩니다.

```text
## 핵심 요약
## 핵심 개념
## 발표 포인트
## 예상 질문
